# Проект PythonDjangoDZ

## Описание:

Проект это веб-приложение на Python для настройки удаленного сервера 
и автоматического деплоя проекта на удаленный сервер

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Skripnik072/HW30.git
```

## Использование:

Требуемые пакеты и зависимости
1. Установите Python 3.13.
2. Установите Django версии 5.2.8.
3. Установите Nginx для обработки запросов.

Настройка сервера
1. Настройте SSH-доступ с использованием SSH-ключей для повышения безопасности.
2. Закройте все ненужные порты, оставив открытыми только те, которые необходимы (например, 80 для HTTP и 443 для HTTPS).
3. Установите и настройте Supervisor для автоматического перезапуска приложения при изменениях.

Деплой
1. Склонируйте репозиторий на сервер.
2. Выполните миграции базы данных с помощью команды python manage.py migrate.
3. Запустите сервер с помощью sudo systemctl restart myapp.service.
