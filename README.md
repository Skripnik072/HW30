# Проект PythonDjangoDZ

## Описание:

Проект это веб-приложение на Python для настройки удаленного сервера 
и автоматического деплоя проекта на удаленный сервер

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Skripnik072/HW30.git
```

## Использование:

Требуемые пакеты и зависимости
1. Установите Python 3.13.
2. Установите Django версии 5.2.8.
3. Установите Nginx для обработки запросов.

Запуск проекта
1. Создайте виртуальную машину, например, в Yandex Compute Cloud. Запустите созданную ВМ, Скопируйте в буфер обмена
публичный IP-адрес запущенной ВМ.
2. В выбранном репозитории (раздел Settings/ Secrets and veriables/ Actions) внесите значения секретных параметров 
для доступа к проекту (DEPLOY DIR - директория для развертывания проекта на сервере, SSH_KEY - публичный SSH- ключ, 
SSH_USER - имя пользователя, SERVER_IP - вставьте IP адрес из буфера обмена).
3. В Pycharm откройте проект PythonPrDPF, Выполните команду Push. 

Деплой
1. Склонируйте репозиторий на сервер.
2. Выполните миграции базы данных с помощью команды python manage.py migrate.
3. Запустите сервер с помощью sudo systemctl restart myapp.service.
