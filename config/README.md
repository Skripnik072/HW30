# Проект PythonDjangoDZ

## Описание:

Проект это веб-приложение на Python для запуска приложения через Docker

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:Skripnik072/HW30.git
```

## Использование:

Порядок запуска приложения:
1. Установите Docker и Docker Compose, если они ещё не установлены.
2. В терминале, перейдите в директорию проекта.
3. Запустите команду: docker-compose up -d --build
